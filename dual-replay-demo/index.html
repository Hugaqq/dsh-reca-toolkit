One interface · two systems

One prompt enters Harness.
An observable production graph comes back.

DSH handles intent, tool orchestration, status and delivery. ReCA handles planning, shared visual state, parallel shots, serial segments, validation, repair and final concat.

How it works

From language to a multi-shot film.

Stay in one Harness conversation while ReCA turns the request into a traceable production plan.

01 · Direct

Describe the film

Give DSH the story, tone and constraints in ordinary language. The agent decides how to call the skill and monitor the job.

02 · Plan

Grow the shot tree

ReCA allocates shots, durations and segment leaves, then creates portraits, locations, props and boundary anchors.

03 · Execute

Render with continuity

Shots can run in parallel. Segments inside a shot remain serial, passing the previous tail into the next generation.

04 · Inspect

Validate and repair

Weak leaves can be flagged, rerolled or prompt-adjusted before every accepted segment is concatenated.

DeepSeek Harness

The agent-facing layer.

  • Understands the creator's request
  • Calls reca_create_video
  • Polls lifecycle state without blocking chat
  • Returns the final artifact and trace

ReCA

The execution layer.

  • Plans Shot and Segment dependencies
  • Maintains shared character and scene memory
  • Routes image and video generation
  • Validates, repairs and concatenates

Workflow

Three visible tool moments.

01
reca_create_video

Submit the creative intent

DSH starts an asynchronous ReCA job and returns a stable run ID immediately.

02
reca_get_status

Follow the production graph

Planning, assets, segments, validation and concat stay readable as lifecycle stages.

03
reca_get_artifact

Receive the film and evidence

The completed MP4 is delivered alongside the persisted artifacts that explain how it was made.
