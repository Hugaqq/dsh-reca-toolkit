# 多镜头展示剧本集（10 支）+ 分镜切换强化提示词

> 基于 `SERVER_STORY_CATALOG.md` 中 30 个历史剧本的成功/失败经验设计。
> 目标：覆盖动作打戏（正反打快速切换）、枪战、追逐、爆炸、生死倒计时、演奏会/音乐会等场景，
> 用 ReCA 的多 shot 规划能力体现"剪辑感"，而不是把所有动作压进一个长镜头。

共同结构（沿用历史成功剧本验证过的格式）：

1. 开头一句定规格：时长、1920x1080、写实电影感、**明确要求"剪成多个镜头"**；
2. 场景 + 人物 + 关键道具一次性锚定（颜色、服装、武器、位置）；
3. 叙事切成 4–5 个只推进一次的节拍，每节拍一句话说清动作与镜头意图；
4. "剪辑与连续性要求"清单：轴线、身份、次数、光线、负面约束；
5. 结尾固定一句：GPT Image 2 参考图 + R2V + "请直接生成最终视频"。

## 二、分镜切换常见问题与强化提示词

以下每条给出问题、成因和可直接粘贴进剧本"连续性要求"段的强化提示词。历史 run 证明：把约束写成"只发生一次 / 始终 / 不要"的祈使句清单，比嵌在叙事段落里有效得多（对比 3.8 与 3.10 的措辞差异）。

### 1. 角色身份/面部漂移（跨 shot 换人）

问题：切镜后角色脸型、发型、体型变化，尤其正反打双方都露脸时容易"融合"成一个人。

强化提示词：

> 两位角色的面部、体型、发型和身份必须在所有镜头中保持一致，正反打切换时不要互相融合或交换面部特征。A 始终是 {外貌锚点}，B 始终是 {外貌锚点}，两人外观差异必须始终明显可辨。

### 2. 跳轴（空间方向翻转）

问题：正反打或追逐剪辑中，人物/车辆的运动方向突然镜像，观众空间感断裂。这是正反打场景的第一大杀手。

强化提示词：

> 正反打切换时严守空间轴线：{甲方}始终在画面左侧朝右，{乙方}始终在画面右侧朝左，任何镜头都不要镜像翻转，不要让两人的相对位置在剪辑中交换。

### 3. 服装/道具不一致或消失

问题：切镜后衣服颜色变了、手里的道具没了、或同一件道具出现两件。

强化提示词：

> {道具}是同一件，状态依次为 {状态链：如 遗落→拿起→携带→归还}，跨镜头连续，不要消失、复制或改变外形。{角色}的{服装}颜色全程不变，夜雨/火光等环境光不得把它渲染成另一种颜色。

### 4. 动作重复（同一动作被重演）

问题：shot 边界处模型"接不上"，把挥棒、剪线、踹门等关键动作又演了一遍；或慢动作堆叠灌水。

强化提示词：

> {关键动作列表}各发生且只发生一次，不要在镜头切换处重演同一姿态，不要原地循环。不要慢动作堆叠，动作按真实速度，只有{指定瞬间}允许一次短暂停顿。

### 5. 武器/人物交换或复制

问题：打戏里两人武器互换、多出第三个分身、凭空新增军队/围观者。

强化提示词：

> 不要交换武器，不要复制人物，不要新增任何角色。全片只有 {n} 个人物：{逐一列出并给外观锚点}。

### 6. 倒计时/计时数字不一致

问题：倒计时特写之间数字跳变、回退、与叙事时间对不上。

强化提示词：

> 倒计时是全片的时间锚点：只能单调递减，只在{指定节拍}加速一次，不能跳变、回退或前后矛盾；每次出现倒计时特写都必须承接上一次出现的数字，归零与{爆炸/终场}严格对应。

### 7. 爆炸/枪火等一次性大事件失控

问题：要求一次爆炸，模型给连环爆炸；枪口焰乱闪与射击动作对不上。

强化提示词：

> 爆炸全片只发生一次，发生在{明确时序位置}，之后只有烟尘，不要连环爆炸。每次射击要有因果：枪口焰、弹壳、着弹点碎屑配套出现，不要凭空开火，不要无人开枪也有枪口焰。

### 8. 光线/色温跨 shot 跳变

问题：夜戏切一镜突然天亮；火场的橘红与警灯的红蓝互相污染；雨突然停了。

强化提示词：

> {主光源}的色温和方向每镜一致，{环境效果：雨/雪/雾}全程持续不要突然停止。内外两个空间的光色必须可区分：{空间A}是{光色}，{空间B}是{光色}，不要混淆。

### 9. 平行剪辑时空混乱

问题：追逐/交叉剪辑里追兵突然超前、两人出现在同一画面却位置矛盾。

强化提示词：

> 平行剪辑保持两条动线独立：{追方}始终落后{逃方}约{距离}，不要在剪辑中突然超前；两条动线交替呈现时，各自的运动方向保持一致（都朝{方向}），不要让他们同框时位置矛盾。

### 10. 演奏/音乐场景的动作-节奏脱节

问题：音乐会场景里运弓/击键动作在镜头切换后倒退重演，掌声插到演奏中途。

强化提示词：

> 演奏段落只能向前推进：{主题→渐强→独奏/华彩→收束}各发生一次，不要在镜头切换后重复同一段手部动作或让音乐情绪倒退。掌声只发生一次，且必须在最后一个音之后。乐手的舞台位置全程固定：{逐一列出方位}，不要在剪辑中换位。

### 11. 人群/背景失控

问题：音乐厅观众忽多忽少、拳台边教练换位、围观者造型突变。

强化提示词：

> 背景人物（观众/乐团/围观者）数量和布局各镜一致，不要增减；关键配角（{教练/指挥}）固定在{位置}。观众面孔可以不同但{服装风格}基调保持一致。

### 12. 通用兜底段（建议每个剧本结尾都带）

> 镜头切换必须服务于叙事节拍，每个镜头只完成自己的一个连续动作；前一个镜头结束时的人物姿态、位置和道具状态必须与后一个镜头开场衔接。不要出现文字、字幕、水印或现代物品（古装题材）。使用 GPT Image 2 生成人物、场景和关键道具参考图并保持参考资产贯穿整个视频，让 Wan 3.0 默认采用 R2V。

## 三、使用建议

- **剧本已经内置强化约束**：10 个剧本的"剪辑与连续性要求"段就是上述提示词按题材的实例化，可直接投喂。
- **追求更强剪辑感**：在剧本开头补一句"由 ReCA 的 planner 自己决定镜头数量、景别和分镜边界，不要把正文当成已经写好的镜头表"（见目录 3.30 / 6.1 的成功措辞），把分镜粒度交给 planner。
- **追求精确控制**：参考 6.2《回到站台的灯下》的写法，显式给"镜头 N / 世界时间 / 运镜"表——但目录 6.2 的注释提醒这不适合展示 ReCA 自主分镜能力。
- **时长与 shot 数经验**：历史成功 run 中 60s 剧本通常规划出 5–7 个 shot；超过 7 shot 且含大量桥接时失败率上升（3.21 的 80s/7 shots 失败），所以本批剧本把单支时长控制在 60–90s、节拍 4–5 个。
